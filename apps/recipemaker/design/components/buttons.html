Buttons

One primary action per screen. Everything else steps back — a page of equally loud buttons tells the user nothing about what to do next.

Variants

Small

Icon — row controls

When to use which

VariantUse for
PrimaryThe one action the screen exists for — Save, New recipe, Sign in
SecondaryA real alternative, not a lesser one — Cancel, Export
QuietAdditive actions inside a form — Add ingredient, Add note. No border, so rows stay calm
DangerDestructive and irreversible. Tinted, never solid red — solid red draws the eye to the thing you least want clicked
IconRepeated row controls. Always aria-labelled; the glyph alone is not a name

Disabled means saved

The primary button reads Saved and disables when there is nothing to save. That is deliberate feedback, not a dead control — it answers "did that go through?" without a toast.
