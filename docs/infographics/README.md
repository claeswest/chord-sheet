## Notes

- These are **documentation assets, not site assets**. Nothing here is served to
  visitors. If you ever want one on the public site, copy it into `public/`.
- AI exports are often 1–3 MB. If the folder gets heavy, re-save as JPEG (quality
  ~85) or WebP — a poster loses nothing visible and shrinks by roughly 10×.
- Regenerating? Use the same chat/session so the set keeps one visual style, and
  re-run the whole set rather than mixing old and new looks.
